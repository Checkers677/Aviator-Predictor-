📖 About the Project

OLD-STUDIO Virtual Predictor is an educational AI simulation that demonstrates how prediction systems can be built using TensorFlow.js in the browser.
It allows users to select previous outcomes and see a simulated “next prediction” with confidence levels and visual effect



🚀 Features

Fully browser-based, no backend required.

Real-time machine learning demo using TensorFlow.js.

Saves last selected results in local storage.

Retrain and reset buttons for better user interaction.

Beautiful responsive design with dark theme.

💡 How It Works

1. Select the previous, second, and latest results.


2. Click Predict to generate a simulated prediction.


3. Retrain or reset the model anytime.
