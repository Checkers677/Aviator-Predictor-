## About
OLD-STUDIO is a polished research prototype demonstrating a prediction workflow implemented entirely in-browser using **TensorFlow.js**. The model is trained on synthetic data to show the pipeline: data generation, model architecture, training, prediction, logging, and visualization.

> **Important:** This is a research prototype using synthetic data. It does **not** connect to or predict outcomes of any live betting or gambling system. Use it for demonstration, experimentation, and reporting.

## Features
- Browser-only ML demo using TensorFlow.js.
- Mobile-first, polished tech-dashboard UI.
- Inputs: previous, second, latest ranges.
- Generates a numeric prediction + confidence and maps to a labeled range.
- Saves last inputs and logs to `localStorage`.
- Training-loss chart, exportable CSV log, and virtual stake simulation.
- Contact & channel links included for project follow-up.

## Files
- `index.html` — main page (mobile-first).
- `style.css` — styling for tech-dashboard look.
- `script.js` — app logic, TF.js model, UI handlers.
- `README.md` — this file.

## How to run
1. Put the files in the same folder.
2. Open `index.html` with Chrome, Edge, or Firefox (mobile or desktop).
3. Select three last results and press **PREDICT**. Use **Retrain** to train the prototype and **Export Log CSV** for reporting.
